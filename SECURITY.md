# Security and privacy issues

ChamBoard's whole purpose is privacy, so a bug that leaks typed text, adds a way for the
keyboard to reach the network, or lets one app see a draft meant for another is a security bug.

Please report these privately, using GitHub's **Report a vulnerability** button on the
repository's **Security** tab, rather than in a public issue. Include the steps to reproduce and
the Android version.

Known limits that the keyboard cannot fix (motion sensors, a compromised phone, what you choose to
send) are listed in [`docs/guide/limits.md`](docs/guide/limits.md).
